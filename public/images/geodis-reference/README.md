# GEODIS Warehouse Reference Images

These images were provided by a GEODIS employee for use in WarehousePro.

Files are numbered in their original attachment order:

- `geodis-warehouse-reference-01.png` corresponds to the original `Image.png`.
- `geodis-warehouse-reference-02.png` through `geodis-warehouse-reference-12.png` correspond to the original `Image (1).png` through `Image (11).png`.

The assets are stored under `public/images/geodis-reference/` and are available to the application at `/images/geodis-reference/<filename>`.

Before public production rollout, GEODIS Operations or IT should confirm the permitted use, storage, and display of each image. Do not expose images containing employee, customer, order, or restricted operational information without approval.
